peer-contract v0.1

A generic protocol for agent-to-agent communication. Five JSON Schemas, zero-dep CLI, OpenClaw plugin enforcing 9 hard rules in enforce mode.

v0.1.0 MIT 166/166 tests 5/7 e2e PASS + 2/7 e2e BLOCK (correct) OpenClaw 0.7.1+
Strategic purpose

When agents (LLM-driven or otherwise) delegate work to each other, three things go wrong without a contract layer: implicit routing, context leakage, and broken chains of accountability. peer-contract v0.1 fixes all three with explicit routing (HR1), self-contained payloads (HR4), immutable acceptance criteria (HR7), and an append-only audit trail (HR5). The OpenClaw plugin enforces 9 hard rules at runtime in enforce mode, with intent-aware HR1 and cross-agent-to-work blocking per the strategic design intent.

The three problems

1
Implicit routing

Work lands on the wrong session (often the coordinator's main) because the dispatcher had to guess a target.

2
Context leakage

The receiver inherits too much or too little state, and either over-acts or under-acts on the request.

3
No accountability

No audit trail of who-dispatched-what-with-what-AC, so the chain of responsibility breaks down.

The protocol fixes all three

✓
Explicit target_session_key

Every dispatch carries the target. HR1 (no-default-to-main) blocks implicit routing.

✓
Self-contained payloads

Explicit context_scope with HR4. No "look this up" implicit references.

✓
Frozen AC + audit trail

HR7 immutability for acceptance criteria. HR5 audit log per cross-session query.

Cross-agent dialogue and bus/work separation

Each agent has a public bus boundary and a private work sub-session. The protocol enforces two layouts: cross-agent dispatch goes bus↔bus (ALLOW), and any cross-agent direct-to-work is BLOCKED by HR1.

Two-agent dispatch with bus↔work session model

    Ab->>Bb: dispatch (target=B.bus, payload=v0.1)

    Bw->>Bw: execute task

Strategic design intent (user拍板)

  • One-shot: v0.1 is a one-shot protocol layer. No v0.2 (user explicit 9/22 9:48).
  • Enforce mode: dryRun: false (user 6/22 06:09). No shadow mode shipped.
  • Strategic scope = agent↔agent: HR1/5/6 enforced at runtime. HR2/3/9 dormant (B方案 user拍板 7/14).
  • Cross-agent-to-work blocked: agent-A.bus → agent-B.work is anti-pattern (user architectural critique 9/22 9:21).
  • v1.1 wire format dropped: Producers must emit v0.1 format (user 6/14).
